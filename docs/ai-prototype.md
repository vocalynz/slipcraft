# SlipCraft AI Prototype

## Goal

Introduce practical AI-assisted workflows for SlipCraft while keeping the system developer-friendly.

## First Prototype: Receipt Intelligence Assistant

The first AI capability will focus on structured receipt assistance.

### Planned workflow

1. User provides receipt information.
2. Assistant analyzes the data.
3. Assistant suggests improvements.
4. User reviews and accepts changes.

## Example Capabilities

- Detect missing receipt fields
- Suggest cleaner descriptions
- Categorize expenses
- Generate receipt summaries
- Help developers create test data

## Development Notes

The AI layer will be designed as an independent service so future integrations can support multiple AI providers.
