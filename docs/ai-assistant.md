# SlipCraft AI Assistant

## Overview

SlipCraft AI Assistant is a planned developer and maintainer tool that uses AI capabilities to improve receipt workflows and project maintenance.

## Planned Features

### Receipt Intelligence

- Extract structured receipt information
- Suggest missing receipt fields
- Improve merchant data quality

### Developer Assistance

- Generate API documentation
- Suggest tests
- Help contributors understand the codebase
- Assist with issue analysis

### Maintainer Workflow

- Summarize bug reports
- Draft release notes
- Improve contributor onboarding

## Goal

Use modern AI tooling to make digital receipt infrastructure easier to build, maintain, and extend.
