# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and respectful environment for everyone contributing to SlipCraft.

## Expected Behavior

- Be respectful and constructive.
- Welcome different perspectives.
- Focus on improving the project.
- Help new contributors learn.

## Unacceptable Behavior

Harassment, discrimination, or disruptive behavior is not acceptable.

Thank you for helping build a positive open-source community.
