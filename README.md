# SlipCraft - Open Receipt Platform

SlipCraft is an open-source platform for creating, managing, and integrating digital receipts.

Built with Laravel, Inertia.js, React, and Tailwind CSS.

## 🚀 Overview

SlipCraft provides a foundation for receipt workflows, merchant tools, and developer integrations. The goal is to make digital receipt infrastructure easier to build, extend, and maintain.

## ✨ Features

- ✅ Receipt generation workflows
- ✅ Responsive React interface
- ✅ Vendor management foundation
- ✅ Dashboard experience
- ✅ Payment workflow foundation
- ✅ Developer-focused roadmap

## 🎨 Technology Stack

- Frontend: React 18
- Routing: Inertia.js
- Styling: Tailwind CSS
- Build Tool: Vite
- Backend: Laravel

## 🛠️ Local Development

```bash
npm install
npm run dev
```
